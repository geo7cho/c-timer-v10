# 상담 타이머 앱 (counseling_timer_app)

## 먼저 꼭 읽어주세요 — 왜 APK 파일을 바로 드리지 못했나요?

이 앱은 안드로이드 네이티브 빌드 도구(Gradle + Google/Maven 저장소)를 인터넷에서
내려받아야 컴파일이 됩니다. 그런데 지금 이 대화가 실행되는 클라우드 환경과,
연결된 PC의 빌드용 가상환경 양쪽 모두 보안상 `dl.google.com`, `maven.google.com`,
`repo.maven.apache.org` 같은 주소가 막혀 있어서, 여기서는 실제 APK 파일을
컴파일할 수 없었습니다. (일반 앱스토어/npm/pypi 주소는 열려 있지만, 안드로이드
빌드에 필요한 구글 저장소만 막혀 있는 구조입니다.)

대신 **바로 빌드 가능한 완성된 소스 코드 전체**를 준비했습니다. 빌드하는 방법은
두 가지가 있습니다.

- **컴퓨터에 아무것도 설치하고 싶지 않다면** → `GITHUB_SETUP.md` 파일을 열어
  그대로 따라 하세요. 무료 깃허브 계정만 있으면 깃허브의 서버가 대신
  apk를 빌드해줍니다. (권장 - 아래 1~4단계를 몰라도 됩니다)
- **PC에 Flutter를 직접 설치해서 빌드하고 싶다면** → 아래 1~4단계를 따라 하세요.

## 구현된 기능 요약

1. 시작 화면에서 세션 시간을 00:30(30분) ~ 03:00(3시간) 사이에서 5분 단위로 설정
   (자주 쓰는 30/45/50/60/90/120/180분 프리셋 버튼 포함)
2. "세션 녹음" 켜기/끄기 토글
3. 시작을 누르면 화면에서 카운트다운 진행, 설정 시간이 되면 차임벨(딩동댕) 알람음 재생
4. 알람음은 안드로이드는 **알람(STREAM_ALARM) 오디오 스트림**, 아이폰은
   **AVAudioSession playback 카테고리**로 재생되어 무음/진동 모드에서도 들립니다
   (알람 앱들이 쓰는 것과 동일한 방식입니다. 단, 기기의 "알람 볼륨" 자체를
   0으로 낮춰둔 경우까지 강제로 소리 낼 수는 없습니다)
5. 녹음을 켠 경우, 세션 종료 시 자동으로 녹음을 멈추고
   `상담_20260831_143000.mp3` 형식(날짜_시간)의 MP3 파일로 변환하여 저장
6. 앱 내 "저장된 녹음" 화면에서 저장 폴더 경로와 파일 목록을 보여주며,
   **가장 최근 녹음이 맨 위**에 오도록 정렬되어 있음 (재생/공유/삭제 가능)
7. **일련번호 인증 + 기기 잠금**: 앱을 처음 실행하면 일련번호를 입력해야
   사용할 수 있고, 한 번 인증된 일련번호는 그 폰에만 묶여서 다른 폰에
   복사해서 설치해도 새로 인증하지 않으면 동작하지 않습니다. 개인 고객에게
   한 분씩 판매하실 때, 고객마다 다른 일련번호를 드리는 용도로 쓰시면 됩니다.

## 사전 준비물

- Windows/Mac 컴퓨터 (일반 인터넷이 되는 평소 사용하시는 PC면 됩니다)
- 무료 계정만 있으면 됨 (Google Play 개발자 계정 없이 APK 설치/테스트 가능)

## 1단계 — Flutter 설치

1. https://docs.flutter.dev/get-started/install 접속
2. 사용 중인 OS(Windows/Mac)에 맞는 설치 파일을 내려받아 설치
3. 설치 후 터미널(명령 프롬프트)에서 아래 명령으로 정상 설치 확인:
   ```
   flutter doctor
   ```
   "Android toolchain" 항목에 체크가 안 되어 있다면, Android Studio를 설치하고
   `flutter doctor --android-licenses` 로 라이선스에 동의해야 합니다.
   (Android Studio: https://developer.android.com/studio)

## 2단계 — 프로젝트 뼈대 생성 후 소스 교체

Flutter 프로젝트는 `flutter create` 명령으로 안드로이드/아이폰 네이티브
프로젝트 뼈대(껍데기)를 자동 생성해야 합니다. 그 위에 제가 만든 소스 코드를
덮어씌우는 순서로 진행합니다.

1. 원하는 작업 폴더로 이동 후 실행:
   ```
   flutter create counseling_timer_app
   cd counseling_timer_app
   ```
2. 방금 생성된 폴더 안의 `lib` 폴더와 `pubspec.yaml` 파일을 삭제하고,
   이 zip 안에 들어있는 `lib` 폴더와 `pubspec.yaml`로 교체(복사)하세요.
3. 이 zip 안의 `assets` 폴더(알람음 포함)도 프로젝트 최상위로 복사하세요.
   (즉 `counseling_timer_app/assets/sounds/alarm_chime.wav` 위치가 되어야 합니다)

## 3단계 — 권한 추가

1. `android/app/src/main/AndroidManifest.xml` 파일을 열고,
   이 zip의 `android_manifest_snippet.xml`에 적힌 3줄의 권한을
   `<manifest>` 태그 바로 아래에 추가하세요.
2. `ios/Runner/Info.plist` 파일을 열고,
   이 zip의 `ios_info_plist_snippet.xml`에 적힌 마이크 권한 설명을
   `<dict>` 태그 안에 추가하세요. (안드로이드 APK만 필요하면 이 단계는 건너뛰어도 됩니다)

## 3-1단계 — 일련번호(라이선스) 서버 설정 (판매용으로 복사 방지가 필요할 때)

앱을 개인 고객에게 판매하시면서, 고객마다 다른 일련번호를 드리고 그 번호를
입력한 폰 1대에서만 동작하도록(다른 폰에 복사해도 안 되도록) 하는 기능이
이미 코드에 들어있습니다. 서버라고 해도 별도 호스팅비 없이 무료 Google
계정만으로 운영할 수 있는 방식(Google 시트 + Apps Script)으로 만들어
두었습니다.

1. https://sheets.google.com 에서 새 스프레드시트를 하나 만듭니다.
2. 시트 하단 탭 이름을 더블클릭해서 `licenses` 로 바꿉니다.
3. 1행(맨 윗줄)에 아래 6개 열 제목을 순서대로 입력합니다
   (이 zip의 `license_server/licenses_sheet_header.csv` 파일을 열어 그대로
   복사해 넣으셔도 됩니다):
   ```
   serial | device_id | status | note | created_at | activated_at
   ```
4. 메뉴에서 `확장 프로그램 > Apps Script`를 클릭합니다.
5. 열린 편집기의 코드를 모두 지우고, 이 zip의 `license_server/Code.gs` 내용을
   전체 복사해서 붙여넣은 뒤 저장합니다(디스크 모양 아이콘 또는 Ctrl+S).
6. 편집기 우측 상단 `배포 > 새 배포`를 클릭합니다.
   - 유형 선택(톱니바퀴)에서 "웹 앱"을 선택
   - "다음 사용자로 실행": 나
   - "액세스 권한이 있는 사용자": 전체(익명 사용자 포함)
   - 배포를 누르면 처음엔 Google 계정 권한 승인 화면이 나오는데,
     본인 계정이므로 "고급 > 안전하지 않음(이동)"을 눌러 승인해주면 됩니다.
7. 배포가 끝나면 `https://script.google.com/macros/s/ABC.../exec` 형태의
   웹 앱 URL이 나옵니다. 이 주소를 복사하세요.
8. 이 프로젝트의 `lib/config.dart` 파일을 열어
   ```dart
   const String licenseServerUrl = '';
   ```
   의 따옴표 안에 방금 복사한 URL을 붙여넣습니다.
9. 시트로 돌아가 새로고침하면 상단 메뉴에 "라이선스 관리 > 일련번호 20개
   생성" 메뉴가 생깁니다. 이걸 눌러서 판매용 일련번호를 미리 만들어 두거나,
   시트에 직접 원하는 문자열(예: `MYAPP-0001`)을 `serial` 열에 한 줄씩
   입력해도 됩니다. `status` 열은 `활성`으로 둡니다.
10. 이제 `flutter build apk --release`로 빌드하면, 앱을 처음 켤 때 일련번호
    입력 화면이 뜹니다. 고객에게 시트에 있는 번호 하나를 알려주시면, 그 번호를
    입력하는 순간 그 폰에 묶이고 시트의 `device_id` 칸에 자동으로 채워집니다.
    (device_id는 폰의 고유번호가 아니라 "이 앱이 설치된 자리"를 가리키는
    값이라, 고객이 앱을 지웠다 다시 깔면 새 인증이 필요합니다 — 이때는 시트에서
    해당 줄의 `device_id` 칸을 지워주면 같은 번호로 다시 인증할 수 있습니다.)
    나중에 특정 고객의 사용을 막고 싶으면 `status` 칸을 `차단`으로 바꾸면
    됩니다.

**정직하게 말씀드리면**, 이 방식은 "일반적인 복사 방지"로는 충분히 실용적이지만
(고객이 APK 파일만 복사해서 다른 폰에 옮겨도 새 인증 없이는 못 씀),
100% 완벽한 해킹 방지는 아닙니다. 마음먹고 apk를 분해(디컴파일)해서 인증
로직 자체를 지워버리는 수준의 시도까지 막으려면 코드 난독화, 서버 쪽 추가
검증 등 훨씬 복잡한 작업이 필요합니다. 일반적인 개인 판매 시나리오(고객이
번호를 다른 사람에게 그냥 나눠주지 못하게 막는 정도)에는 이 정도로 충분합니다.

## 4단계 — 패키지 설치 및 빌드

```
flutter pub get
flutter build apk --release
```

빌드가 끝나면 아래 경로에 APK 파일이 생성됩니다:

```
build/app/outputs/flutter-apk/app-release.apk
```

이 파일을 안드로이드 폰으로 옮겨서 설치하면 됩니다
(폰 설정에서 "출처를 알 수 없는 앱 설치" 허용 필요).

테스트만 해보고 싶다면 `flutter build apk` 대신
```
flutter run
```
을 사용해 USB로 연결한 폰에서 바로 실행해볼 수도 있습니다.

## (선택) 컴퓨터에 아무것도 설치하지 않고 빌드하고 싶다면

Codemagic(https://codemagic.io), GitHub Actions 등 무료 클라우드 빌드
서비스에 이 프로젝트 폴더를 올리면, 여러분의 PC에 Flutter를 설치하지 않고도
자동으로 APK를 만들어 다운로드 링크를 받을 수 있습니다. 필요하시면 이 방법도
단계별로 안내해 드릴 수 있습니다.

## 알아두시면 좋은 점 (다음 단계로 개선 가능한 부분)

- 현재 버전은 **앱이 화면에 켜져 있는 동안(포그라운드)** 정확하게 동작하도록
  설계되어 있습니다. 화면이 꺼지지 않도록 자동으로 막아주지만(Wakelock),
  만약 상담 중 폰을 완전히 잠그거나 다른 앱으로 오래 전환해도 3시간까지
  안정적으로 카운트하게 하려면, 안드로이드 "포그라운드 서비스" +
  iOS 백그라운드 오디오 모드를 추가하는 2차 작업이 필요합니다. 실제 사용해보시고
  필요하면 이 부분을 추가해 드릴 수 있습니다.
- 알람음은 기본 제공되는 "딩동댕" 차임벨(assets/sounds/alarm_chime.wav)이며,
  원하시는 다른 소리 파일(mp3/wav)로 같은 파일명으로 교체하면 바로 바뀝니다.
- 녹음 파일은 앱 전용 저장공간에 보관되어 "저장된 녹음" 화면에서만 보이며,
  일반 파일관리자(다운로드 폴더 등)에서 바로 보이게 하려면 안드로이드
  MediaStore 연동이 추가로 필요합니다.
- 아이폰(iOS) 빌드는 반드시 Mac + Xcode가 있어야 가능합니다
  (Apple 정책상 Windows에서는 iOS 앱을 빌드할 수 없습니다). 안드로이드와
  코드는 100% 공용이므로, Mac이 준비되면 같은 소스로 `flutter build ios`만
  실행하면 됩니다.
